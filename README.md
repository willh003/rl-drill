# learnmax

Spaced reps of anything
- Create decks (with ai, or by yourself using the ui)
- Get reminders to do reps throughout the day
- Review on phone via web app or locally via the desktop app

Comes with stuff I've been reviewing (ml basics, music basics, etc)

Built on top of [arabic-drill](https://github.com/willmanidis2/arabic-drill), with a couple of modifications (flashcards, card editor, separate decks).
